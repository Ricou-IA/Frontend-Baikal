## 4. Pièges connus (payés au Sprint 1)

- `out_project_identity` de `rag.get_agent_context` n'a **pas** de clé `name` (seulement `description`, `market_type`, `project_type`) : le nom du projet se lit dans `core.projects`.
- Le CCAG n'est pas un fichier de projet : `sources.files` `layer='app'`, `project_id` null. Toute résolution « par projet » le déclare absent.
- Le `\m` / `\M` de Postgres ne coupe pas sur `_` (`'2139_PGC.pdf' ~* '\mpgc\M'` est faux) : bornes en `[^a-z0-9]`.
- Dans une chaîne `.or()` PostgREST, les motifs ne contiennent ni virgule ni parenthèse ; l'opérateur regex insensible à la casse est `imatch`.
- `sources.files` a un index sur `project_id` (`idx_sources_files_project_id`) mais pas d'index utilisable pour un `~*` : une requête par type reste un scan filtré par projet, acceptable.
- `REFUSAL_PATTERNS` du harnais (`eval/run-eval.ts`) est une liste de regex : toute nouvelle formulation de refus voulue par le prompt doit y être ajoutée, sinon les C7 passent en échec.
- Les environ 200 conversations créées par chaque campagne d'éval restent dans `rag.conversations` (ids dans `eval/reports/*.conversations.json`) ; purge sur demande d'Eric seulement.
